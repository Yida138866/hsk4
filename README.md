# HSK 4 系统学习 · Học HSK 4 có hệ thống

Static study site for HSK 4: a 10-week plan, 602 words, 100 grammar points, flashcards, a placement test and lesson quizzes.

- `/` is the Chinese–Vietnamese version (中文–Tiếng Việt)
- `/en/` is the Chinese–English version

Plain static files with no server and no tracking. Study-plan progress is saved in the browser's localStorage.
Built from `source/` with `python3 source/build.py`, which needs Node, `react`, `react-dom` and `esbuild`.
